# ADR-0001 — ثبت تصمیم‌های معماری به‌صورت ADR

**Status:** Accepted · **Date:** 2026-09-12

## Context
پروژه‌ای با عمر بلند، چند مشارکت‌کننده (تیم پژوهشی + فنی) و دامنه‌ی بحث‌برانگیز تاریخی.
بدون ثبت «چرا»، هر مشارکت‌کننده‌ی جدید طراحی را از نو زیر سؤال می‌برد و دانش از دست می‌رود.

## Decision
1. هر تصمیم معماری که **هزینه‌ی بازگشت بالایی** دارد در `docs/adr/NNNN-title.md` ثبت می‌شود.
2. قالب: Status / Context / Decision / Consequences / Alternatives considered.
3. ADRها **تغییر نمی‌کنند**؛ superseded می‌شوند (با لینک به ADR جدید).
4. تغییر بزرگ معماری بدون ADR = نقض `AGENTS.md` (قانون ۱۶).

## Consequences
- مثبت: onboarding سریع، جلوگیری از بحث تکراری، قابلیت حسابرسی علمی.
- منفی: هزینه‌ی نوشتن (که عمداً پذیرفته می‌شود).
